## Selected projects

### [Ames House Price Prediction](https://github.com/kamelch/ames-house-price-prediction)

Explore housing data, prepare features, and compare Ridge regression models for predicting sale prices in Ames, Iowa.

**Focus:** data cleaning, feature engineering, and regression modeling.  
**Tools:** Python, pandas, scikit-learn, matplotlib, and Jupyter.

### [Open Food Facts Analysis](https://github.com/kamelch/open-food-facts-analysis)

Investigate a historical food-product dataset through missing values, product categories, ingredients, additives, and nutrition-score patterns. Saved notebook outputs make the analysis available to browse.

**Focus:** exploratory analysis, data quality, and visualization.  
**Tools:** Python, pandas, seaborn, SQLite, and Jupyter.

### [FluxPresso Espresso Controller](https://github.com/kamelch/fluxpresso-espresso-controller)

An embedded project for a Gaggia espresso machine, with ESP32-S3 firmware, a touchscreen interface, and wiring documentation.

**Focus:** sensor integration, control logic, and hardware documentation.  
**Tools:** C++, ESP32-S3, LVGL, and PlatformIO.
